## Reflection Phase — Overview

The task execution is complete. You and your team will now go through **three reflection phases** to improve for future tasks. Your improvements (patches, skills, profiles, team structure) will persist and be used in all subsequent tasks.

**Phase 1 — L1 Self-Reflection**: Each agent reflects on their own performance and records improvements (behavioral patches, skills).

**Phase 2 — L2 Collaboration Reflection**: Each agent reflects on interactions with teammates and records collaboration patterns in teammate profiles. Reusable directed handoff contracts are reflected separately from the observed execution trace and persisted by the team-level handoff reflector.

**Phase 3 — L3 Structural Reflection**: The Chairman evaluates the team structure and proposes changes (new agents, constitution updates, configuration changes).

The system manages phase transitions automatically. Complete each phase using the provided tools, then wait for the next phase.
